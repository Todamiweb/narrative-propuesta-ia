# Propuesta Narrative Studio AI

Presentación interactiva para proponer a empresas grandes una iguala mensual de desarrollo de sistemas de IA.

- Un solo archivo: `index.html` (sin dependencias ni compilación).
- El nombre del cliente se cambia en la constante `CLIENTE`, al inicio del script.
- Teclas: → y espacio avanzan, ← retrocede, I abre el índice, F pantalla completa, R repite animaciones, `#n` en la URL abre la diapositiva n.

Ver en local:

```bash
python3 -m http.server 4322
```
